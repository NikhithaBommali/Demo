# NC DHHS Phase Assessment Dashboard

Frontend-only static React prototype for the NC DHHS Phase Assessment Dashboard.

## Current dashboard sections

The prototype currently includes 5 navigation tabs:
- Overview
- Provider Readiness Detail
- Vendor Evaluations
- AI Governance Risks
- Audit/Provenance

## Notes

- The Overview experience includes the former ROOTS Hub Regional Disparities content as part of the same section.
- All data is static and defined locally in `frontend/src/App.tsx`.
- No backend calls, runtime fetching, or external data sources are used.
